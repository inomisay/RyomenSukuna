# Ryomen Sukuna — 宿儺 · King of Curses

A cinematic, single-page fan tribute to Ryomen Sukuna from *Jujutsu Kaisen*. Six scenes, stepped through with the arrow buttons, the keyboard, the mouse wheel or a swipe.

| # | Scene | What happens |
|---|---|---|
| 1 | Title | Sukuna, eyes closed |
| 2 | The King wakes | His eyes open, with crimson slashes across the frame |
| 3 | Domain Expansion | The hand seal forms and Malevolent Shrine (伏魔御廚子) detonates |
| 4 | The vessel | Move the cursor to uncover what is underneath |
| 5 | Fuga | The arrow of flame, from the fight against Jogo |
| 6 | Outro | "Stand proud. You are strong." |

## Run it

No build step and no dependencies to install. Clone the repo and open `index.html` in a browser.

```
git clone https://github.com/inomisay/RyomenSukuna.git
```

Fonts and GSAP load from a CDN, so you need to be online the first time.

## Help make it better

The media is the weakest part, and I would love better versions. If you find or make a sharper clip or a better image, please open an issue or a pull request — I want to hear about it.

| File | Used for | What would improve it |
|---|---|---|
| `Fuga - Arrow Flames.mp4` | Fuga scene | Only 360p with burned-in subtitles; a 720p+ clean version |
| `eyes opening.mp4` | Title and waking scenes | A version where the second pair of eyes opens too |
| `hand-sign.mp4` | Domain scene | Fine as is; higher resolution welcome |
| `img/sukuna_face.jpg` | Vessel scene, top layer | Any moody close-up, 16:9 |
| `img/sukuna_smirking.png` | Vessel scene, revealed layer | Ideally the same pose as the top layer |
| `img/sukuna_on_throne.jpg` | Domain reveal | Higher resolution |
| `img/sukuna_portrait.jpg` | Outro background | Higher resolution |

Keep the same file name and a 16:9 frame and a replacement works with no code change. Ideas for new scenes and fixes to the code are just as welcome.
